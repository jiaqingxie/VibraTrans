remain in the archived public version, outside this manuscript's scope.

`Strict_loss/training_per_seed.csv` distinguishes strict ablations, reused
controls and completion of nine previously interrupted original fits. The
numerical divergence is retained; missing downstream results are not fabricated.
This three-term study excludes the variance-normalized term in every arm and
does not ablate the final four-term primary recipe.

Detailed values and drawing summaries represent different aggregation levels,
not independent replicates. Reference descriptor-label files exclude historical
predictions. Figure 5 retains its explicitly identified archived VAE control.
The SHA256 manifest identifies the files. Finished figure layouts and molecular
insets are not regenerated by the minimal software demonstration.
